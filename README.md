# 🚀 FlyMenu V4

A stylish neon GUI for Roblox Studio, built with Luau.

## ✨ Features
- ⚡ Adjustable movement settings
- 🎥 Freecam
- 👁️ ESP
- 📊 FPS counter
- 🧍 Character settings
- 🌈 Lighting controls
- 💜 Neon design with a draggable interface

## 📦 Installation
1. Open the `FlyMenuV4.client.lua` file.
2. Copy the script into your own Roblox Studio project.
3. Test and customize it to your needs.

## 🛠️ Customization
Adjust settings to create your preferred experience.

**Version:** 4.0  
**Language:** Luau
